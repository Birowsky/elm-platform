# @birowsky/elm-platform-darwin_arm64

The Elm compiler binary for macOS on Apple Silicon, built from `compiler/` in [elm-platform](https://github.com/Birowsky/elm-platform). You don't install this yourself: [`@birowsky/elm-platform`](https://www.npmjs.com/package/@birowsky/elm-platform) depends on it.

It is **unofficial**, and not affiliated with or endorsed by the Elm project or Evan Czaplicki. The Elm compiler is BSD-3-Clause, see `LICENSE`. The binary also contains the GHC runtime and libraries it was built with.
